# 徐迪专业硕士论文评审原则笔记（MEM/MBA 应用型）

蒸馏自徐迪公众号《管理学学位论文写作》系列（本地 34 篇）。短引均标注出处；未在原文中明确写出的归纳标为「系列主题推断」。

---

## 1. 问题导向（核心）

- 科学研究四段论：**问题、假设、论证、结论**；学位论文应按此逻辑表述，而非教科书的「概念→理论→方法→示例/案例」。（徐迪公众号｜什么是问题 / 修订版）
- 中文「问题」多层含义：topic（主题）、issue（议题）、question（疑问）、problem（难题）、defect/error（缺陷/错误）。管理学研究主要面对 **question（解释）** 与 **problem（解决）**。（徐迪公众号｜什么是问题修订版）
- 专业硕士：**以真实企业的具体 problem 为导向**；须用数据/事实提出问题；再分析成因，把 problem 转化为可研究的管理 **topic**；再据此应用既有理论方法设计方案并检验效果。（徐迪公众号｜什么是问题修订版；专业学位论文自检表）
- 勿混淆：**problem ≠ 成因 ≠ topic ≠ 理论/方法问题**。常见失败：把「供应商管理粗放」当 problem，或把「建立评价体系」当 problem 写进导论第一节。（徐迪公众号｜什么是问题修订版）
- 题目以 **管理 topic + 具体企业** 为核心；理论/方法仅可作辅助，忌喧宾夺主成「方法导向」。（徐迪公众号｜选题；问题导向示例；自检表）
- 示例：宜「某电商企业生鲜供应商**管理改进**研究」，不宜仅「供应商**评价**研究」（评价是手段）。（徐迪公众号｜问题导向示例）

---

## 2. 不是教科书 / 不是工作报告

- 学位论文不是知识传播导向的教科书，不宜设「理论基础」章机械罗列概念与教材内容；也不宜写成工作报告、操作手册、管理指南的指令语气。（徐迪公众号｜文献综述和研究现状；常见问题三则；八股和八卦）
- 标题宜用 **名词性陈述词组**，忌动宾指令式、结论式、口号式（如「强化XX管理」「XX水平低」）。（徐迪公众号｜常见问题三则；自检表）
- 课程学习逻辑 vs 学位论文逻辑：前者应试、标准答案；后者问题自提、第三方评审答辩。（徐迪公众号｜研究生课程学习与学位论文）

---

## 3. 摘要须独立成文

- 摘要是学位论文缩写，**可脱离正文独立存在**；四大要素：研究了什么、为什么、怎么研究、有什么结论。（徐迪公众号｜摘要；摘要、引言和结论的区别与联系）
- 推荐三段式：背景/问题/意义（约 1/5）→ 内容方法过程（约 3/5）→ 结果结论（约 1/5）。（徐迪公众号｜专业学位论文自检表）
- 忌：前言式、目录/结构式、解释专业术语、无结论、专业硕摘要留白过多。（徐迪公众号｜摘要；自检表）
- 英文摘要指代学位论文用 **thesis / dissertation**，不用 paper、article、essay。（徐迪公众号｜学术论文与学位论文；自检表）

---

## 4. 结论 ≠ 总结

- 「总结」偏工作报告；「结论」适合科学研究论证结果。专业硕士通常只研究一个问题，末章宜用 **结论**，不宜用「总结」作章标题。（徐迪公众号｜结论和总结）
- 末章任务：回顾研究工作 → 给出结论并呼应导论意义（管理启示即可）→ **研究展望**（内容与方法上的后续可能）。（徐迪公众号｜结论和总结；研究展望）
- 专业硕士一般**不要求也不宜硬写理论创新/理论贡献**；有实践意义与管理启示即可。（徐迪公众号｜研究意义…；研究创新；自检表）
- 展望忌「水平有限、时间不够」等谦辞，亦忌只堆局限而不谈后续研究空间。（徐迪公众号｜研究展望；自检表）

## 5. 学术型 vs 专业型结构

| 维度 | 学术型（对照） | 专业硕士（本 rubric 对象） |
| --- | --- | --- |
| 问题来源 | 文献中一类问题；可强调理论/方法贡献 | 亲身经历的具体企业具体 problem |
| 意义 | 理论+实践；结论可谈贡献 | 主要为实践意义；结论谈管理启示 |
| 文献 | 常独立成第2章系统综述 | 「研究现状」即可；可放导论第2节；忌教科书式「理论基础」 |
| 本论 | 按方法/子问题展开（实证或建模等） | 典型三块：现状与成因 → 方案设计 → 实施与效果 |
| 普适性 | 常期望外推 | **不要求普适性**；解决真实问题即可（徐迪公众号｜评审答辩若干问题辨析） |

结构模板见：徐迪公众号｜专业硕士学位论文正文的章节结构；学术型对照见同系列学术型章节结构文。

## 6. 方法必须贴合问题

- 研究方法须**针对具体研究内容**，有系统性和独特性；忌罗列「文献研究法、案例研究法、比较分析、实地调查、定性定量结合」等放之四海皆准的说法。（徐迪公众号｜研究方法；文献研究与文献研究法）
- 「文献研究」≠「文献研究法」：前者支撑研究现状；后者是可独立完成结论的方法，专业硕几乎不适用作方法声明。（徐迪公众号｜文献研究与文献研究法旧文重发）
- 研究对象企业本身不是「案例」；「以XX企业为例」副标题常错位——企业是研究对象本身。（徐迪公众号｜选题；八股和八卦；自检表）
- **企业真实经营数据优先**；问卷/访谈仅在无法获取所需数据时使用，不是专业硕硬性要求。（徐迪公众号｜专业学位论文评审和答辩若干问题辨析）
- 方法是否「适合」某类问题：应以应用效果与论证合理性判断，不宜仅凭课程刻板印象一票否决；创造性迁移且有真实结果数据者宜包容。（同上辨析文）
- 技术路线 ≠ 章节结构图；技术路线非必需，章节结构必需。（徐迪公众号｜自检表；研究内容）

---

## 7. 摘要 / 导论 / 结论分工

- 摘要：压缩四大要素，少分析讨论。
- 导论：详述问题与意义、研究现状、内容方法、论文结构；第一节标题突出**问题**（「研究问题及其意义」），非「研究背景及意义」。（徐迪公众号｜八股和八卦；自检表）
- 结论：回顾 + 结论/启示 + 展望，呼应导论承诺。（徐迪公众号｜摘要、引言和结论的区别与联系）

---

## 8. 答辩与评审陷阱

- 答辩 PPT 逻辑应接近摘要四大块，**勿按章节机械翻讲**；宜图文并茂，目视听众。（徐迪公众号｜评审和答辩；答辩报告的一种模式）
- 一种推荐模式：① 研究问题及其意义 → ② 文献/研究现状 → ③ 内容方法过程（含实施或保障与效果）→ ④ 研究结论与展望。（徐迪公众号｜答辩报告的一种模式；答辩报告示例）
- 格式与行文低级错误会占满评议时间；专业硕尤甚。（徐迪公众号｜评审和答辩）
- 忌 PPT 末页「感谢聆听」（谦辞错位）；着装与在场礼仪属综合素质。（徐迪公众号｜评审和答辩）
- 答辩 = defence：证明达到学位水平，勿不战而降。（徐迪公众号｜研究展望）
- 「答辩的可能」文列举失败类型（选题错、结构不合理、理论/方法错、逻辑矛盾、抄袭、写成工作报告或教科书等）——评审时应主动排查，而非仅作轶事。（徐迪公众号｜答辩的可能）

## 9. 系列后期对早期观点的更新 / 强化

本地语料无统一公历年份；下列以**修订版、重发、辨析、自检表、答辩模式**相对同主题早期文的关系为准（若外部以 2024–2025 年推送计，则属系列后期更新）：

1. **什么是问题（修订版）** 相对初版：系统区分 topic / issue / question / problem；强调成因≠问题；题目须 topic 导向而非方法导向；明确「并非所有 problem 都是管理问题」。评审以修订版为准。
2. **专业学位论文自检表**：将选题、摘要、导论、本论、结论、参考文献、标题体例、图表等收束为可执行检查表——本 checklist 的主骨架。
3. **评审和答辩若干问题辨析**：明确反驳「必须有问卷访谈才算研究」「结论必须普适」「方法不在课程体系就不能用」等评审误区；强化企业数据与专业硕定位。
4. **答辩报告的一种模式**：在早期「答辩报告示例」与「评审和答辩」技巧之上，给出更简洁的四段结构模板。
5. **文献研究与文献研究法（旧文重发）**：再次强调勿把「文献研究法」当作方法；方法须系统性与独特性。
6. **问题导向、素质教育及其它** 标注「旧文重发」并称问题愈演愈烈——问题导向原则未改，语气更强调方法炫技之害。

## 10. 评审者使用提示（系列主题推断）

- 先判学位类型：若按学术硕/博士标准苛求理论创新、普适性、问卷实证，即偏离徐迪专业硕标准（推断自辨析文 + 研究创新文）。
- 闭环检查：导论提出的 problem ↔ 成因章 ↔ 方案章对应关系 ↔ 效果数据 ↔ 结论启示 ↔ 展望。（推断自自检表本论三项 + 章节结构）
- 不确定是否徐迪原文原话时，在评审意见中写「据系列主题」或「据自检表」，勿杜撰「徐迪认为…」的新主张。
