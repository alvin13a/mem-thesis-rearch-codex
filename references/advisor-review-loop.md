# 导师视角自动审查闭环（出完整粗稿）

正文某一章或全文**AI 初稿写完后，必须立刻进入本闭环**，不要把「请用户自己审」当作结束。目标：交给用户的是**已自检并改过一轮（或标明仍缺料）的完整粗稿**，外加「导师评价」清单。

## 角色

模拟严格但建设性的专硕导师（徐迪问题导向 + 学校常识），不是替用户做学术不端，也不编造数据来「补洞」。

## 步骤 R1 — 自动审查

对照 `review-checklist.md` + `rubric-notes.md`，输出三块：

1. **致命问题**（不改不能交）：problem 不一致、方案不对题、效果无回扣、编造嫌疑、缺独立文献章、空方法标签等  
2. **应改问题**（结构/表述/图表/引用）  
3. **通过项**（已达标，避免重复改）

每条写清：**位置（章/节）→ 问题 → 改法（可执行）**。

额外专检：

- 第2章是否有文献依据；引用是否可回溯；是否做过 literature-assist  
- 图表是否三线表/论文图规范；有图无释读否  
- 摘要三段式；结论有无自贬套话  

## 步骤 R2 — 自动修订（在权限内）

对「应改 / 致命」中**不依赖新企业数据、新文献全文**的条目，**直接改稿**（统一术语、理顺逻辑、补图题表题与引用句、删空泛方法、把无据数字改回 `【待用户补充】`）。

对仍缺用户材料的条目：保留占位 + 汇总到「尚需用户补料」列表（对应 G1–G6），**不要编造补齐**。

## 步骤 R3 — 交付「完整粗稿」包

一次交给用户：

1. **粗稿正文**（已过 R2 的最新稿）  
2. **导师评价**（R1 精简版：致命 / 已自动改 / 待你补料后才能改）  
3. **图表清单**（已生成文件 + 题注；未生成的缺料说明）  
4. **下一步**：若有待补料，按关卡列出；无则提示可进入格式排版/答辩稿  

用户未要求「停止自动审查」时，**禁止**只丢初稿就结束。
