# 常见论文图与素材

| 类型 | 典型用途 | 用户需提供 | 默认工具 |
|---|---|---|---|
| 柱状/条形图 | 对比指标、前后效果 | 类别 + 数值 CSV | make_basic_charts.py |
| 折线图 | 时间序列 | 时间 + 数值 | 同上 |
| 饼/环图 | 结构占比（慎用，类别≤6） | 类别 + 占比 | 同上 |
| 分组柱 | 方案前后对比 | 多系列 CSV | 同上 |
| 流程图 | 计划编制/审批/实施 | 步骤与判定 | 结构图脚本或重绘 |
| 框架/架构图 | 方案模块关系 | 模块与连线 | 同上 |
| 泳道/职责图 | 部门协作 | 角色×活动 | 同上 |
| 甘特/节点图 | 实施计划 | 任务与时间 | 同上 |
| 重绘论文原图 | 按评审改图 | 原图 + 意见 | 对照重出 |

风格：白底、黑灰主色、可加 1 个强调色；无 3D、无剪贴画、无过度渐变。
