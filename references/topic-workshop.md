# 选题工坊模板（专硕 / MEM）

依据徐迪：题目以**具体企业或项目的管理主题（topic）**为核心；problem 须有事实与数据；理论方法仅可选前缀。

## A. 先填这张卡（用户必填，缺项则停）

| 字段 | 说明 | 用户填写 |
|---|---|---|
| 企业/项目全称 | 研究对象本身，不是「以…为例」 | |
| 你的角色/可及数据 | 为何能拿到内部事实与数据 | |
| 可观察的病灶 problem（2–5条） | 负面可感知结果，附指标/事实 | |
| 每条 problem 的证据 | 报表、工单、延期率、访谈纪要等 | |
| 初步成因（管理因素） | 不是把成因当成 problem | |
| 拟用的管理 topic | 如供应商管理、多项目进度、缓冲管理 | |
| 候选理论/方法（可选） | 仅工具，不喧宾夺主 | |
| 方案能否落地/已落地 | 未实施则需保障措施与预期效果口径 | |
| 合同/工期/组织约束 | 专硕叙事常涉及 | |
| 学校格式要点 | 学校规范优先于体例细节 | |

## B. 题目模板（生成 2–3 个候选供用户选）

首选：
- `Z公司（或项目）T管理改进研究`
- `Z公司T管理优化研究`
- `基于X方法的Z公司T管理改进研究`（仅当方法确为执行核心且不抢 topic）

避免：
- 无企业名的宏大题
- `…：以Z企业为例`
- 关于/初探/浅析/浅谈/探究/探索/探析
- 纯方法题把管理 topic 挤掉

## C. 过关标准（选题未过关不得开写正文）

1. 能指认具体组织；
2. 每条 problem 有证据来源；
3. problem ≠ 成因 ≠ topic 三者分得清；
4. 能写成「实践意义」一句话；
5. 用户明确选定一个题目（或改稿确认）。
