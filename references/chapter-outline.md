# 专硕正文骨架（默认）

按徐迪专业硕士学位论文常见结构组织。**本 Skill 默认把「文献综述 / 研究现状」写成独立第2章**（勿写成「理论基础」教科书体）。学校若强制五章或把文献并入导论，从其模板，但须在大纲里显式说明映射，不得默默省略文献章。

## 默认六章结构

### 第1章 导论
- 素材关卡：G1；涉及图表时加 G6
- 节次建议：
  1. 研究问题及其意义（背景铺垫 + 分条 problem + 实践意义）
  2. 研究内容
  3. 研究方法与（可选）技术路线 / 适用性
  4. 论文结构
- **不要**把完整文献综述塞进本章（可一句预告「第2章综述…」）
- 写作要求：用事实提出 problem；专硕只需实践意义；勿编造文献、勿硬凑理论创新

### 第2章 文献综述（或「××管理研究现状」）
- 素材关卡：**G3**（必过）；有对比表时加 G6
- 节次建议（按问题侧面组织，勿按「作者罗列」）：
  1. 章前语（本节围绕哪些问题侧面）
  2. 与 problem 相关的理论 / 方法 / 实践评述（夹叙夹议）
  3. 现有研究或实践与本案的差距（Gap）
  4. 对本文方法与方案的依据 / 借鉴
  5. 本章小结
- 写作要求：
  - 问题导向：为研究必要性与方法可行性提供依据，不是概念科普
  - 禁用「理论基础」章名；忌国内外两分空架子
  - **先执行** `references/literature-assist.md`：自动检索候选表 + **提示用户上传** PDF/题录；未上传不写综述正文
  - **禁止编造文献条目**；无清单时只给检索词与提纲 + `【待用户补充：文献】`
  - 专硕可偏「研究现状 / 实践借鉴」，仍须评述而非堆砌

### 第3章 企业/项目现状与问题成因
- 素材关卡：G1、G2、G6
- 节次建议：生产/业务特征与职责 → 流程现状 → 问题相关指标现状 → 成因分析 → 本章小结
- 写作要求：指标定义、统计口径、分析范围写清；用证据检验成因假设；勿用「管理不完善」当结论；problem 与第1章一致

### 第4章 改进方案（全文核心）
- 素材关卡：G2 成因依据、G3 方法依据、G4 方案约束、G6
- 节次建议：方案总体思路 → 与各 problem 一一对应的子方案 → 保障/落地要点 → 本章小结
- 写作要求：方案与 problem 一一对应；方法具体、可操作；有理论/方法/实践依据

### 第5章 方案实施与效果分析
- 素材关卡：G5、G6
- 节次建议：实施过程或实施计划 → 效果指标前后对比（或预测口径）→ 本章小结
- 写作要求：效果回扣第1章 problem；未实施须标注「未实施/待数据」并写清保障与预测口径

### 第6章 结论
- 研究总结（铺垫）→ 研究结果 → 研究结论 → 研究展望
- 勿「水平有限」自贬；可不设本章小结

## 学校强制「五章」时的映射

优先保留**独立第2章文献综述**，例如：

1. 导论  
2. 文献综述  
3. 现状与问题成因  
4. 改进方案  
5. 实施与效果（章末并入简短结论）  

或学校书面要求把文献并入导论时：第1章含「研究现状」小节，后续章号前移——**须在大纲首行注明「按学校模板：文献并入导论」**，并仍过 G3。

## 辅文与体例

摘要（三段式）、关键词、参考文献、致谢、附录。  
标题用名词性词组；章导语/小结体例全篇一致（导论、结论可不设本章小结）；图表均有正文解读。
