# 第2章文献协助（自动检索 + 用户上传）

进入独立第2章（或任何需要综述/引用）时，**先跑本流程，再写正文**。禁止编造作者、年份、期刊名、DOI、结论。

## 目标

让用户手里有一批**可核验、可下载**的文献，再写夹叙夹议的综述；不是替用户「生成假参考文献」。

## 步骤 A — 自动检索推荐（Agent 必做）

根据已定题目、problem 列表、行业/方法关键词，用当前环境可用的检索能力（WebSearch、学术站、浏览器、学校库链接等）检索，输出一张**候选文献表**（不少于 8–15 条，中英文搭配）：

| # | 题名 | 作者 | 年份 | 来源（期刊/会议/报告） | 链接或 DOI | 与本案哪条 problem/方法相关 | 获取难度（OA / 需库 / 需购买） |

要求：

1. 每条必须有**可打开的链接或 DOI**；打不开的不要硬写进表冒充已核实。
2. 优先：近 5–10 年核心期刊/知名会议、行业白皮书、国家标准；**不建议**把其他专硕/学硕学位论文当作主要参考文献。
3. 按问题侧面分组（如：交付延期、在制品、MPS/APS、看板与拉动…），便于第2章结构。
4. 同时给出 5–10 组**检索式**（中英文），方便用户自己在知网/万方/维普/Google Scholar/Semantic Scholar 补检，例如：  
   `"生产计划" AND 交付延期`；`MPS APS due-date performance`；`WIP reduction production planning`。
5. 标明推荐阅读优先级：★必读（写 Gap/方法依据） / ☆选读。

## 步骤 B — 明确提示用户上传（Agent 必做，写正文前等待）

用一段简短中文提示用户（可复制）：

> 第2章文献综述需要你提供真实文献，我不能编造条目。请任选一种方式补料后回复「文献已上传」：  
> 1）把上面候选表里能下的 PDF/CAJ 直接拖进对话；  
> 2）导出知网/万方「题录」（RIS / BibTeX / NoteExpress / EndNote）文件上传；  
> 3）粘贴你已有的参考文献列表（GB/T 7714 或学校格式均可）；  
> 4）若学校有指定必引教材/标准，一并上传封面页或目录页。  
> 下完后告诉我：哪些★必读你已拿到全文，哪些只有摘要。

未收到上传/题录前：

- 只允许：综述提纲、候选表、检索式、`【待用户补充：文献 PDF/题录】`
- **禁止**：虚构引用、伪造页码、假装已读全文后写评述段落

## 步骤 C — 收到材料后

1. 盘点：已有全文 / 仅题录 / 仍缺的★必读。  
2. 请用户确认是否授权用已上传文献写第2章（默认：上传即授权用于本论文草稿）。  
3. 按 `chapter-outline.md` 第2章结构起草；每条引用对应真实材料；缺全文处写 `【待全文：题名】` 只作观点占位、不编造细节。  
4. 同步维护「拟用参考文献」清单（学校格式），供文末参考文献用；**不建议大量引用学位论文**。

## 步骤 D — 方法匹配（与 G3 后半段一起）

在文献依据之上，列出 2–3 个**具体结构化方法**选项（模型/算法/评价体/流程框架等），说明与本案 problem 的匹配理由；禁用「文献研究法、案例研究法、定性定量相结合」等空标签。用户选定后再写导论「研究方法」与方案章方法段。

## WorkBuddy / Codex 工具提示

- 有联网：优先 WebSearch / 浏览器打开 DOI、Semantic Scholar、Google Scholar、出版社页，核对题名与年份。  
- 知网等需登录：把检索式与候选表交给用户，提示在校园网/VPN 下载后上传。  
- 切勿用「根据一般知识」捏造看似真实的参考文献。
