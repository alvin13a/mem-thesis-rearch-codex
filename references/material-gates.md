# 素材关卡（写到哪一章，缺什么就停）

**总规则：**没有用户提交的真实材料，只输出提纲与「【待用户补充：…】」占位，禁止编造企业数据、访谈原话、实施效果数字、**文献条目与文献结论**。

| 关卡 | 触发时机 | 必须向用户索取 | 未收到时允许输出 |
|---|---|---|---|
| G0 选题 | 未定题 | 填完 topic-workshop；选定题目 | 候选题目与追问 |
| G1 问题证据 | 导论问题节前 | problem + 事实/指标 | 提纲 + 待填空 |
| G2 成因与现状 | 现状/成因章前 | 组织、流程、角色、成因证据 | 提纲 |
| G3 文献与方法 | 第2章文献综述前；研究方法前 | ① literature-assist 候选表；② **等待上传** PDF/题录；③ 具体方法名 | 候选表、检索式、提纲；不编造文献、不假装已读写正文 |
| G4 方案 | 方案章前 | 约束、边界、决策依据 | 骨架 |
| G5 实施与效果 | 实施/效果章前 | 日志/节点；前后数据或预测口径 | 标注未实施/待数据 |
| G6 图表 | 插图插表前 | 表数据或图文件/草图；本包内用 scripts 出**三线表**与论文图 | 表头框架；无数不填 |
| G7 导师审查 | 章或全文初稿完成后（自动） | （可选）学校格式手册；待补料清单中的材料 | 按 advisor-review-loop 输出评价并自动可改项；交付完整粗稿 |

用户说「文献已上传」「这是表5-1」等 → 从中断关卡继续。
