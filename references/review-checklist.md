# 专业学位论文评审清单（徐迪标准）

主要依据：《专业学位论文自检表》，并交叉《什么是问题（修订版）》《常见问题三则》《答辩报告的一种模式》《评审和答辩若干问题辨析》等。每条：**通过 / 存疑 / 不通过**。

## 1. 题目与选题

1. 题目落到**具体企业或具体项目**的具体管理主题（topic）。失败样例：无企业名的「企业供应商管理优化研究」。
2. 不以理论/方法喧宾夺主。失败样例：纯「X理论在Y企业的应用研究」却无清晰管理 topic。
3. 不以「以Z企业为例」把研究对象降成例子；Z 应是研究对象本身。
4. 无「关于、初探、浅析、浅谈、探究、探索、探析」等词；宜用「研究」。
5. 导向是**解决真实 problem**，不是写教科书或追求普适理论贡献。

## 2. 摘要与关键词

6. 摘要独立完整：研究了什么、为什么、怎么研究、有什么结论。
7. 宜三段式：背景问题意义≈1/5；内容方法过程≈3/5；结果结论≈1/5。
8. 非前言式、非目录/结构式、不解释专业术语堆砌。
9. 英文摘要用 thesis/dissertation，不用 paper/article/essay 指代学位论文。
10. 关键词规范、对应主题/理论方法；避免过宽（如「企业管理」）、中文关键词夹无必要英文缩写、非著名企业名堆砌。

## 3. 导论（问题链）

11. 第一章标题用导论/绪论等，不用「前言/序言/序」。
12. 第一节突出**研究问题及其意义**，而非仅「研究背景及意义」。
13. 用**数据和事实**提出具体企业的具体 problem；分清 problem 与成因。
14. 第一节末段交代研究目的：成因分析→管理 topic→方案→实施与效果。
15. 专硕一般只要**实践意义**，不硬凑理论意义。
16. 研究内容通常含：现状与成因；理论方法支撑的方案；实施与效果。
17. 研究方法写**具体结构化方法**（模型/算法/评价体等），禁用空泛「文献研究法、案例研究法、定性定量相结合」等。
18. 不把技术路线当成章节结构复述；章节结构必需，技术路线非必需。
19. 专硕不要求研究创新/理论贡献；有管理启示即可。
20. **默认第2章为独立文献综述/研究现状**（学校另有模板从其规定并写明映射）；勿以「理论基础」教科书式罗列概念；勿把完整综述只塞在导论一小节后就跳过第2章。
20b. 第2章写作前是否已提供候选文献表并**提示用户上传** PDF/题录？引用元数据是否均可回溯（无编造作者/年份/期刊）？

## 4. 本论（方案与证据）

21. 本论大致对应研究内容三块，方案章为全文核心。
22. 现状章提出的 problem 与导论第一节**一致**。
23. 方案有理论/方法/实践借鉴支撑，并与前述 problem **一一对应**。
24. 效果分析回扣前述 problem，有充分详实的数据对比。
25. 企业真实经营/项目数据是合格甚至优选来源；无问卷访谈**不是**缺陷（无法取得企业数据时才需要）。
26. 方法是否「适合」看论证与效果数据，不能仅凭课程是否教过或刻板印象一票否决。

## 5. 结论与展望

27. 结论含研究总结（铺垫）→研究结果→研究结论；展望宜独立成节。
28. 章名不用「总结」替代「结论」。
29. 展望谈后续研究内容/方法可能性，突出本研究重要性；勿过度自贬「水平有限、时间不够」等（形同自证不合格）。

## 6. 参考文献与辅文

30. 参考文献按学校规范；**不建议**大量引用学位论文（尤其其他专硕论文）。
31. 避免低水平短篇非专业期刊「论文」；体现学术品位。
32. 致谢实事求是、有个人特色，忌套路抄袭。
33. 附录放不宜进正文的数据/代码/证明等。

## 7. 体例、标题、图表、章导语

34. 章节目编号体系统一（勿混用多种国标编号体系）。
35. 标题用**名词性词组**，忌动宾指令式、结论式、口号式（「强化XX」「XX水平低」等）。
36. 若设章导语：各章一致；表述方式与篇幅逻辑一致。
37. 本章小结应有实质信息；导论章与结论章可不设小结。
38. 图表须被正文引用并解读，禁止「如图所示」甩图。

## 8. 答辩材料（若有 PPT）

39. 块1：研究问题及其意义（企业现状→problems→成因→管理 topic→意义）。
40. 块2：文献/研究现状（依据方法借鉴，勿机械讲概念教科书）。
41. 块3：研究内容、方法与过程（方案；未实施则保障与预期效果，已实施则过程与效果）。
42. 块4：研究结论与进一步研究可能。
43. 忌生搬模板、缺块、逻辑乱、简单复述目录。

## 评审态度

- 专硕标准 ≠ 学硕/博士标准；勿用「普适性不足」「只有企业数据」否定合格专硕。
- 对作者弱势表述保持善意，但致命逻辑问题必须标出。
